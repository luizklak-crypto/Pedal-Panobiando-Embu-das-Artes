# Pedal Turbo 3D — Realistic Premium Edition (4.1)

Jogo para celular e computador, hospedável gratuitamente no GitHub Pages.

## Publicar no repositório que você já usa
1. Descompacte o ZIP.
2. Abra https://github.com/luizklak-crypto/Pedal-Panobiando-Embu-das-Artes
3. Na branch `main`, use **Add file → Upload files**.
4. Envie **index.html**, **style.css** e **game.js** da pasta `pedal-turbo-premium-v41` diretamente na raiz (sem colocar dentro de outra pasta). O `README.md` é opcional.
5. Confirme em **Commit changes**; se o GitHub pedir para substituir arquivos, confirme.
6. Na aba **Actions**, espere a última execução `pages build and deployment` ficar verde.
7. Abra https://luizklak-crypto.github.io/Pedal-Panobiando-Embu-das-Artes/ e use Ctrl+Shift+R para atualizar.

## Controles
Celular: botões esquerda, pular, direita, turbo, além de deslizar.
Computador: setas / A e D para mudar de faixa, Espaço / seta cima para pular, Shift ou T para turbo.

## Requisitos
Conexão à internet para carregar Three.js pelo CDN. Nenhum servidor de backend é necessário. Recordes são salvos no navegador local.

## Observação visual
O ciclista é construído por geometrias 3D com formas mais arredondadas, e não um modelo humano fotorealista. Para realismo de personagem ainda maior, será necessário incluir um modelo humano GLB/GLTF com rig e animações, devidamente licenciado. A marca exibida é texto estilizado, e não o arquivo oficial do logo Panobianco.
