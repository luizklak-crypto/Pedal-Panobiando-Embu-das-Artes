# Pedal Turbo 3D – Realistic Edition

Versão 4.0 do jogo da Panobianco Embu das Artes.

## Arquivos
- `index.html`
- `style.css`
- `game.js`
- `README.md`

## Publicação no GitHub Pages
1. Abra o repositório no GitHub.
2. Clique em **Add file > Upload files**.
3. Envie os arquivos `index.html`, `style.css`, `game.js` e `README.md` para a raiz do repositório.
4. Confirme em **Commit changes**.
5. Aguarde o workflow do Pages terminar.
6. Abra o link público do site.

## Controles
- **Celular**: botões na tela e swipe.
- **Computador**: setas, A/D, W/Space e Shift/T.
